# Official chapter lists (fill these in before using the app)

The app and the pack generator take chapter names from here, not from AI memory.

## How to fill one file
1. Open https://ncert.nic.in and go to Textbooks. Choose the class and subject for the **2026-27** session.
2. Copy the chapter titles from the book's contents page, in order.
3. Edit the matching file, for example `class-9-maths.json`:
   - Put the book title in `"book"` (for example "Ganita Manjari").
   - Put the chapter titles in `"chapters"`.
   - Set `"verified": true` only after you have checked against ncert.nic.in.
4. Files with `"verified": false` are ignored, so students still get the AI-generated lists for those until you finish them.
